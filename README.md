# test-repo-for-dsh-super-agent

Sandbox repository for dsh-superagent (a proactive coding agent for one repository).

How it works: comment `@matys-dsh-agent <request>` on an issue and a ticket appears in the panel.

## Usage

Mention `@matys-dsh-agent` in a comment on any issue in this repository and describe what you want changed. The request shows up as a ticket in the dsh-superagent panel, the agent makes the change on its own branch, and it opens a pull request for you to review. Keep commenting in the same issue to ask follow-up questions or request changes; this repository is a sandbox, so its contents are only test data.
